# Экран /checkout-v2 — оформление, v2

- **Роут:** `/#/checkout-v2`.
- **Файлы:** `CheckoutV2Screen.vue` и `parts/`:
  - `CheckoutFormV2.vue`, `QuickOrderFormV2.vue`, `RecipientFields.vue`, `ModeSwitch.vue`.
- **Макет:** Checkout-v2 `fCa1yysqLNrhQCioRjN8CF`, фрейм «Checkout — DS» `1:1048`.
- `/checkout-accordion` остаётся прежним, новый экран сделан рядом.

## Состав

**Шапка**
- `CheckoutHeader`. «Передзвонити вам?» включает быстрый заказ.

**Левая колонка**
- Заголовок.
- `ModeSwitch` «Звичайне оформлення | Швидке замовлення» (Figma 10:1880). Это радиогруппа, выбор переключается стрелками.
- **Звичайне** — `CheckoutFormV2`. Лежит на фоне без рамки, секции разделены `border/divider`.
  - **Одержувач** — `RecipientFields`:
    - Прізвище и Ім'я;
    - «Додати по батькові» открывает поле шириной в одну колонку, под «Прізвище»;
    - Телефон и Е-пошта;
    - «Додати коментар до замовлення» с иконкой `comment-stroke` (Figma 1:1137).
  - **Доставка:**
    - Країна;
    - Місто: список из строк `SelectRichOption` с галочкой у выбранной, как у оплаты;
    - способ доставки — `Select size="rich"`: служба, логотип, цена;
    - отделение (список в том же стиле) и «Обрати на мапі», либо адрес курьера, либо адрес магазина.
  - **Оплата:** `Select size="rich"`: способ и условие.
  - `CheckoutConfirm`.
- **Швидке** — `QuickOrderFormV2`, сокращённая полная форма в том же стиле:
  - «Одержувач» с короткой подсказкой и тем же `RecipientFields`: по батькові, комментарий;
  - тот же `CheckoutConfirm` с чекбоксами и кнопкой.
  - Доставку и оплату уточняет менеджер.

**Правая колонка (480)**
- `OrderCard split scroll-hint` — две карточки.
- **Сводка** (Figma 1:1167, 1:1172):
  - строка промокодов: чипы и «Додати код»;
  - по клику поле открывается **под** строкой, крестика закрытия нет;
  - пустое поле скрывается по клику мимо или по Esc;
  - предупреждение;
  - `OrderSummary`, у строк скидок крестик: `DiscountLine removable` снимает код.
- **«Ваше замовлення · N товарів»:**
  - заголовок 32 плюс граница 1 px (Figma 1:1164); граница появляется только при прокрутке списка;
  - список прокручивается внутри, внизу затухание.
- **Опт в `CartItem` Compact** — кнопки порогов (слот wholesale, Figma 6349:456):
  - клик ставит количество, равное порогу, в обе стороны;
  - достигнутый порог показан кнопкой Primary с `aria-pressed`;
  - при достигнутом пороге зачёркнута цена до опта: за штуку — у цены, × количество — над суммой, как у набора (Figma 1:1175). Цена «до скидки» (oldPrice) в это время не показывается.

## Зависимости доставки и оплаты

Работают только на /checkout-v2, в `CheckoutFormV2`.
- **«Самовивіз з магазину»** → оплата только «Готівкою при отриманні». Вторая строка «Оплата в магазині, без комісії».
- **«Покупка частинами» от monobank** → доставка только Новой Почтой.
- Когда вариант остаётся один, вместо селекта показывается статичная строка `SingleOption` с причиной под ней (research_single_option.md).
- Второй список остаётся селектом: если поменять его, первый снова станет списком, так что тупика нет.

## Данные

Общий mock-store `src/data/checkout.ts`:
- опт — массив порогов, функции `wholesaleTiers`, `setWholesaleQty`, `crossedPrice`, `wholesaleOldSum`;
- у способов доставки поля `name`, `sub`, `logo`, у способов оплаты поле `sub`;
- список городов `cityOptions`;
- поля формы `patronymic`, `showPatronymic`;
- быстрый заказ — `submitQuick(['lastName', 'firstName', 'phone', 'email', 'comment'])`.

## Отступления от макета

| В макете | В коде | Почему |
|---|---|---|
| Select «Місто» размера M (32) | L (40) | Похоже на ошибку в макете: остальные поля размера L |
| Подпись поля доставки «Назва поля» | «Спосіб доставки» | В макете заглушка |
| Заголовок карточки товаров «Одержувач замовлення» | «Ваше замовлення · N товарів» | В макете заглушка |
| Вторая строка поля доставки «60 грн» | «від 60 грн, за тарифами перевізника» | Так согласуется со строкой «Доставка» в сводке |
| У кнопок порогов только состояние Default | Достигнутый порог — кнопка Primary | Решение во Vue |
| Логотип Новой Почты вектором | `src/assets/logos/nova-poshta.svg` | Логотипов служб в ДС нет |
| Switch и `comment-stroke` из другой библиотеки | Локальный `ModeSwitch` на токенах ДС, иконка в `assets/icons` | В ДС Store Front их нет |
| Строки открытого списка (`dd-list`) не компонент | `SelectRichOption` есть только в коде | Решено пока оставить только в коде |
