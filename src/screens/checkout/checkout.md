# Экран «Оформлення замовлення» (checkout)

- **Figma:** `Checkout Tabs — Desktop` (6355:10633), макет HOROSHOP-8318 1893:71586.
- **Роут:** `/#/checkout` · файл `CheckoutScreen.vue`.
- **Из базы:** CheckoutHeader (Show callback), Tabs (без линии, gap 24, padding 16), SectionTitle M, Input Size=L ×6, Select Size=L ×3, ButtonFront (Flat M «Додати коментар», Default L «Обрати на мапі», Flat M «Додати код»), Icon, CheckoutConfirm, PromoChip, OrderSummary (без заголовка, скидки, разделителя, кнопки), CartItem Compact ×7 (опт, 2 набора, скидка + мин. заказ ×2, подарок, электронный товар).
- **Локальные блоки (`parts/`):** `CheckoutForm` (единая карточка формы с разделами), `OrderCard` (карточка «Ваше замовлення»). Кандидаты на вынос в базу — если такие же карточки появятся на других экранах (корзина, быстрый заказ).
- **Раскладка:** левая колонка Fill с контентом 600 по центру, правая 500; ≤ 1100 — колонки в столбик; ≤ 900 — в шапке скрыты телефоны; ≤ 600 — скрыта подпись «Повернутись до покупок», ряды полей в столбик.
- **Оживлено (directive_wire_vue, store `src/data/checkout.ts`):** вкладки переключают полную форму / быструю заявку (`parts/QuickOrderForm`: телефон, имя необязательно, «Надіслати заявку»; доставка и оплата скрыты, поля общие); «Передзвонити вам?» → быстрая заявка; поля — v-model, проверка при уходе с поля и при отправке (обязательные, формат телефона / е-пошты); доставка (НП / Укрпошта — отделение обязательно, курьер — адрес, самовывоз) и оплата — списки Select; «Покупка частинами» → Warning в карточке заказа между промокодами и итогами (по копии 1950:21022) и отключение скидок (только в полной форме); промокоды по флоу «додати купон» (Figma 1903:76187): без кодов сразу поле + «Застосувати»; с кодами — чипы + «Додати код», по клику поле встаёт на место строки чипов, Esc — обратно; SMART10 снимается, WELCOME −500, DISCOUNT5 −5% (мок, в макете эффекта нет), несколько кодов — одна строка скидки «Знижка за промокодами …», другое — «Неправильний код»; товары: количество, удаление с тостом, мин. заказ iPhone 2, пустая корзина → EmptyState; условия не приняты или корзина пуста → кнопка недоступна; отправка 1,2 с с «Оформлюємо…», телефон на …000 — тост ошибки, данные сохраняются; успех → `/checkout-success`. «Увійти» → `/checkout-login`, после входа — «Вийти».
- **Тестовые данные:** пароль `password1234`; промокоды `WELCOME`, `DISCOUNT5`; телефон на `000` — сбой отправки.
- **Отличия от Figma:** подписи итогов `text/primary` — переопределение на экране (как instance override в Figma).

- **Настройка «швидке замовлення» (prop `quickOrder`, по умолчанию `true`):** выключено — нет вкладок «Звичайне | Швидке» и ссылки «Передзвонити вам?» в шапке, только полная форма; если был выбран режим «Швидке» — возврат к полной. Плитка `checkout-no-quick` (`/#/checkout-no-quick`) — тот же экран с `quickOrder: false` (поле `props` в реестре экранов).
- **Раскладка без быстрого заказа (только Vue, не в макетах):** десктоп > 1100 — полоса контента 1440 по центру: в ней содержимое шапки и форма; карточка заказа — исключение, всегда у правого края окна (16); форма по центру между левым краем полосы и карточкой; ≤ 1100 — колонки в столбик.
- **Пропорции обычного чекаута (десктоп > 1100, по копии main 1947:20084):** контейнер padding 32 / 32, gap 40, левая колонка тянется, форма заполняет её (без ограничения 600), колонка заказа 480 (сверху 32, снизу 16); контент не шире 1440.
- **Вариант без вкладок (`/#/checkout-accordion`, prop `quickLayout: accordion`, Figma 1991:61158):** над полной формой — сворачиваемая карточка «Швидке замовлення» (`parts/QuickOrderAccordion.vue`: r8, обводка внутрь, отступы 16, иконка fast-24 слева (отступ 8), H4 + P1 + arrow-down-16); раскрыта — форма по Figma 58:8107: «Ім'я та прізвище» (одно поле, делится на имя / фамилию полной формы), «Телефон», «Е-пошта», чекбоксы рассылки и согласия, «Оформити замовлення» (CheckoutConfirm; без согласия неактивна) → экран успеха заявки; «Передзвонити вам?» в шапке раскрывает и прокручивает к карточке; полная форма всегда видна; пока быстрый заказ раскрыт — она бледная (opacity 0,4, плавно), клик или Tab в неё сворачивает быстрый заказ. Колонка заказа делит ширину с формой поровну, но не шире 600 (1280 → 588 / 588, от ~1300 → заказ 600, форма — остальное). Подсказка прокрутки (prop OrderCard `scrollHint`, только этот вариант): в заголовке счётчик позиций «Ваше замовлення · 7 товарів», внизу списка — градиент 48 к surface/default, пока ниже есть скрытые товары; в конце списка и когда всё помещается — исчезает. Обычный `/#/checkout` со вкладками не менялся.

- **Вариант «вкладки-папки» (`/#/checkout-folder`, prop `quickLayout: folder`, Figma 1986:29745):** раскладка и колонка заказа как у варианта с карточкой (заказ до 600, счётчик и градиент). Над формой — вкладки-папки (`parts/FolderTabs.vue`, локально, не в ДС): «Новий покупець» (cart-24 в 16) → полная форма без кнопки «Увійти» (`CheckoutForm` prop `showLogin=false`; `SectionTitle` без действия, строка 40); «Увійти» (user-24) → содержимое попапа входа (`LoginForm`) по Figma 2008:64156: на всю ширину карточки, отступы 24 / 20 / 16, «Увійти» (по контенту) и «Забули пароль?» (flat 32) в одну строку через 16 — раскладка задаётся экраном, попап не меняется, после входа — снова «Новий покупець» с данными аккаунта, вкладка «Увійти» скрывается; «Швидке замовлення» (fast-24) → форма быстрого заказа (`parts/QuickOrderFields.vue`, общая с карточкой). «Передзвонити вам?» открывает «Швидке замовлення». Активная вкладка: surface/default, обводка border/card сверху и по бокам, радиус 8 8 0 0, перекрывает верхнюю границу карточки; у карточки левый верхний угол 0, пока активна первая вкладка. Иконка `cart-stroke` из макета заменена на `cart-24` ДС (тот же контурный стиль).
