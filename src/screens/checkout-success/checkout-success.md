# Экран «Замовлення оформлено» (checkout-success)

- **Figma:** макета нет — собран из базы по PRD (шаг 8 сценария).
- **Роут:** `/#/checkout-success` · файл `CheckoutSuccessScreen.vue`.
- **Из базы:** CheckoutHeader, Icon (tick-16, 40), SectionTitle S, ButtonFront L (Default «Повернутись до покупок», Primary «Оформити ще одне»).
- **Данные:** `checkout.lastOrder` (снимок при отправке): номер, тип (замовлення / заявка), одержувач, доставка, оплата, товары, сумма. Без заказа — переход на `/checkout`. «Оформити ще одне» — сброс store и возврат на оформление.
- **Адаптив:** как у checkout (≤900 / ≤600 — сжатие шапки).
